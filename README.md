# Backpack Battles Godot 4.7 — V0.1

当前本地 PvE 工程的私密版本快照。发布版本为 **V0.1**；游戏内部内容版本与存档格式沿用工程现状。

## 运行与编辑

1. 安装 Git LFS 后克隆本仓库，执行 `git lfs pull` 下载引擎文件。
2. Windows 双击 `launch-game.cmd` 运行；`launch-editor.cmd` 打开随目录提供的 Godot 4.7 编辑器。
3. 也可使用兼容的 Godot 4.7 打开 `project/project.godot`。

完整工程、美术、音效、配置、工具、许可证及验收记录保留。运行缓存、本机 Git 元数据、临时工作目录和玩家个人存档不属于发布内容。

## 当前版本

- 单父菜单图形导航、箭头翻页、新窗口/按钮素材、屏幕道具旋转与放回。
- 标准/教学入口检测有效存档，提供继续或新游戏；明确新局出发后才替换进度。
- 异步资源加载与卸载、界面更新保护机制保留。
- 最新已完成的 UI 回归：23 个进程、1,932 项断言；真实鼠标主流程及道具放回另行验证。历史验证只代表各自报告对应的源码快照。
- 架构阶段只完成 M0 Step 1，后续步骤没有提前实施。

详见 `开始使用.txt`、`点击翻页与继续入口重制_20261027.md`，证据位于 `verification/touch_ui_20261027/`。架构快照位于 `verification/m0_baseline_20261026/`。

本版本针对 Windows GL Compatibility 验证，Android/iOS 尚未真机验收。原有授权与归属说明见 `licenses/` 和工程内对应文件；私密备份不改变素材或代码的授权范围。
